Features

From lead to invoice to payroll — manage your entire business in one place.

Client Management

Full client profiles, contacts, groups, and a dedicated client portal with login.

  • Client portal with project, invoice & ticket views
  • CSV export & advanced search
  • Notes, reminders & GDPR requests

Lead Management

Source, track, score, and convert leads with email integration and web forms.

  • Web-to-lead forms & IMAP email import
  • One-click lead-to-client conversion
  • Pipeline tracking (lost / junk / converted)

Project Management

Gantt charts, milestones, discussions, timesheets, and automatic progress tracking.

  • Gantt chart view & milestone tracking
  • Team discussions with threaded comments
  • File uploads & timesheets per project

Task Management

Kanban board with checklists, timers, assignments, and quick-create modals.

  • Drag-and-drop Kanban board
  • Checklists with reusable templates
  • Built-in start/stop timer

Invoicing

Custom numbering, recurring invoices, partial payments, credit notes, and PDF export.

  • Recurring invoices with configurable cycles
  • Partial payments & multiple payment modes
  • Dual tax per item & credit notes

Estimates & Proposals

Convert estimates to invoices, digital signatures, and public request forms.

  • One-click estimate-to-invoice conversion
  • Digital signature acceptance workflow
  • Public estimate request forms

Support Tickets

Multi-department ticket system with email piping, predefined replies, and client portal.

  • IMAP email piping (auto-import)
  • Predefined replies & spam filtering
  • Client portal submission & replies

Knowledge Base

Public-facing articles with groups, feedback, and staff-only internal documentation.

  • Categorized articles with color groups
  • Visitor feedback (helpful / not)
  • Staff-only internal articles

HR & Payroll

Attendance tracking, leave management with approvals, and payslip generation.

  • Clock in/out with IP logging & grace periods
  • Leave types with quotas & approval workflow
  • Auto-generate payslips with adjustments

Expense Tracking

Category-based expenses, billable to invoices, with recurring and tax support.

  • Expense categories & tax tracking
  • Mark expenses as billable
  • Recurring expense support

Role-Based Access Control

Granular per-feature permissions, departments, two-factor authentication.

  • Per-feature view/create/edit/delete permissions
  • Department-based staff organization
  • Two-factor authentication support

Custom Branding

Brand colors, logo, favicon, custom CSS injection, and configurable footer.

  • Custom primary & secondary brand colors
  • Logo & favicon upload
  • Custom CSS & login background

Quick Start

Clone, install, and run.

# Clone & enter
git clone https://github.com/your-org/khncrm.git
cd khncrm
# Install dependencies
composer install
npm install
# Environment
cp .env.example .env
php artisan key:generate
# Database & seed
php artisan migrate
php artisan db:seed
# Build & serve
npm run build
npm run dev
Or all-in-one: composer run setup
